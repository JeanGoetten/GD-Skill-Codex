## Theoretical Context and System Function

This skill formalizes parallel execution of actions, concurrent resource allocation, and temporal synchronization in digital games using Petri Net Theory. The system is modeled as a directed bipartite graph labeled by the formal quintuple:

$$PN = (P, T, F, W, M_0)$$

where $P$ is the set of Places (conditions/resources), $T$ is the set of Transitions (events/actions), $F \subseteq (P \times T) \cup (T \times P)$ is the Flow Relation, $W: F \to \mathbb{N}^+$ is the Arc Weight Function, and $M_0: P \to \mathbb{N}$ is the Initial Marking.

## 1. Integrated Processing Protocol

When activating this skill, the agent must sequentially execute the following formalization stages:

### Stage 1: Definition of Places ($P$) and Initial Marking ($M_0$)

1. Identify all places $p_i \in P$ representing:
   - **Capacity and Slots:** Available production slots, population limits.
   - **Building/Accumulated Resources:** Discrete tokens of raw materials or energy.
   - **Transient States:** Phases of a process in execution (e.g., *Under Construction*, *On Cooldown*, *Available*).

2. Assign the initial marking vector $M_0 = [M_0(p_1), M_0(p_2), \dots, M_0(p_n)]^T$, where $M_0(p_i)$ indicates the number of marks (*tokens*) present in place $p_i$ at $t = 0$.

### Stage 2: Transition Mapping ($T$) and Arcs ($F, W$)

1. Catalog transitions $t_j \in T$ representing asynchronous actions or system triggers.
2. Define the set of Input Places $\bullet t_j = \{p \in P \mid (p, t_j) \in F\}$ and Output Places $t_j \bullet = \{p \in P \mid (t_j, p) \in F\}$.
3. Determine arc weights $W(p, t_j)$ and $W(t_j, p)$, specifying the exact quantity of marks consumed and generated by each transition.

### Stage 3: Firing Rule and State Dynamics

1. A transition $t_j$ is considered **Enabled** in marking $M_k$ if and only if:

$$\forall p \in \bullet t_j, \quad M_k(p) \ge W(p, t_j)$$

2. Firing $t_j$ produces the new marking $M_{k+1}$ calculated by:

$$M_{k+1}(p) = M_k(p) - W(p, t_j) + W(t_j, p) \quad \forall p \in P$$

with the convention $W \equiv 0$ for non-adjacent (place, transition) pairs — $W$ is only defined on arcs $F$ and the sum runs over all places using that extension.

### Stage 4: Incidence Matrix ($C$) and State Equation

1. Build the Incidence Matrix $C$ of dimension $\vert{}P\vert{} \times \vert{}T\vert{}$, where:

$$C(p, t) = W(t, p) - W(p, t)$$

2. Evaluate temporal dynamics through the fundamental state equation:

$$M_k = M_0 + C \cdot S_k$$

where $S_k$ is the accumulated firing vector indicating how many times each transition has fired up to step $k$. **This equation is a necessary, not sufficient, condition of reachability:** there exist vectors $S$ satisfying it that correspond to no legal firing sequence (spurious markings). Use it to rule reachability *out* and to derive invariants; to rule it *in*, exhibit a firing sequence or run a reachability analysis.

## 2. Algorithmic Analysis of System Properties

The agent must apply the following formal proofs on the $PN$ structure:

### A. Deadlock Avoidance Verification

$$\text{Deadlock} = \{M \in R(M_0) \mid \forall t \in T, \, \exists p \in \bullet t \text{ such that } M(p) < W(p, t)\}$$

Action: Verify if any marking exists in the reachable set $R(M_0)$ where no transition can fire.

### B. Liveness Analysis

Action: Classify the liveness level of transitions:

- **L0 (Dead):** Transition can never fire from $M_0$.
- **L1 (Potentially Firing):** Can fire at least once in some path from $R(M_0)$.
- **L4 (Live):** For every reachable marking $M \in R(M_0)$, the transition can eventually be enabled by some finite firing sequence (not necessarily immediately).

### C. Boundedness Analysis and Resource Conservation

$$\forall p \in P, \forall M \in R(M_0), \quad M(p) \le K$$

Action: Confirm if the number of marks in each place is bounded by $K$, ensuring parallel production does not cause memory overflow or infinite counters.

## Mathematical Status

### Formal Guarantees
A marked Petri net supports verification of decidable properties of the modeled system — conservation invariants, boundedness, enabledness, and liveness of the *formalized* net — but it guarantees nothing about what the net does not model: player comprehension, policy effects outside the net, and gameplay quality.

### Derived Metrics
Derived metrics include utilization, wait time, contention and deadlock incidence.

### Heuristics and Design Judgments
Classify deadlocks as structural, intentional, recoverable or irreversible.

### Required Simulation or Playtesting
Heuristics choose locks and recovery affordances. Required simulation or playtesting: interleaving exploration, stress load and recovery playtests.

## Hypotheses and Limitations

- Assumes token semantics capture capacity and timing; timed, stochastic, and colored nets may require extensions.
- Deadlock, liveness, and boundedness conclusions are conditional on the modeled reachable state space and should be checked globally.

## 4. Procedure Execution Example

Given the game requirement: *"To produce an advanced unit, the player needs 1 free factory slot and 50 minerals. Production consumes the mineral and occupies the slot during the process, releasing the slot and delivering the unit upon completion."*

The agent applying this skill formalizes:

- $P = \{p_{\text{mineral}}, p_{\text{free\_slot}}, p_{\text{in\_production}}, p_{\text{unit\_ready}}\}$
- $M_0 = [100, 1, 0, 0]^T$
- $T = \{t_{\text{start\_production}}, t_{\text{finish\_production}}\}$
- $W(p_{\text{mineral}}, t_{\text{start}}) = 50$, $W(p_{\text{free\_slot}}, t_{\text{start}}) = 1$
- $W(t_{\text{start}}, p_{\text{in\_production}}) = 1$
- $W(p_{\text{in\_production}}, t_{\text{finish}}) = 1$
- $W(t_{\text{finish}}, p_{\text{free\_slot}}) = 1$, $W(t_{\text{finish}}, p_{\text{unit\_ready}}) = 1$
- Incidence matrix $C$. Liveness classification *within the formalized net*: with $M_0(p_{\text{mineral}}) = 100$ and no replenishment transition, $t_{\text{start\_production}}$ can fire at most twice and the net dies afterwards — the honest in-model classification is $L1$, not $L4$. $L4$ (live) holds only for an extended model variant that adds a mineral replenishment transition; if that variant is analyzed, add the transition to $T$ and redo the classification.
